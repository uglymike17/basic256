# testsuite_examples_ci.txt for BASIC256
#
# The programs in Examples/Original_Examples that CI runs one at a time with
# `basic256 -s`. Paths are relative to Examples/Original_Examples, one per
# line; blank lines and lines starting with # are ignored. The runners are
# .github/scripts/run_examples.sh and .github/scripts/run_examples.ps1.
#
# An example passes when it ends on its own inside the time limit, exits with
# code 0 and prints no ERROR. That proves it still compiles and runs to the
# end on the current interpreter; whether a drawing LOOKS right is left to
# testsuite_examples.kbs, the version a person runs from the IDE.
#
# Every example that can do that is listed here. The rest are left out for
# one of these reasons:
#   needs the keyboard, the mouse or INPUT:  15puzzle, cards_deal5, collision,
#       collision3, mousedoodle, paddle, pie_chart, ping, quotations,
#       solar_system, story, teamdatabase, tictactoe, tictactoe_comp,
#       sprites/spritetest3, testing/2darraytest, testing/2dstrarraytest,
#       testing/input_numeric_test, testing/input_string_test,
#       testing/KalRGB, testing/test_dountil, testing/testchr
#   runs until it is stopped:  ballanim, mandelbrot, moving_squares, ring_01,
#       rotating3dcube, sliceanimation, snowflakes, sqrt,
#       imgload/animatedhelp, sprites/spriteslice, sprites/spritetest2,
#       testing/testtime
#   plays sound (the CI machines have no audio):  dice/dice,
#       sound/wavplaystop, sprites/breakout
#   uses the network:  everything in networking/
#   stops on an error on purpose:  errortrapping, imgload/imgload,
#       testing/uaarray
#   broken on the current interpreter:  testing/global_array_test (CALL
#       without brackets), testing/test_slice (old PUTSLICE form),
#       testing/testimagesave (IMGSAVE to GIF is not supported)
